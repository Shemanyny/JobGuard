Security Policy

Our Commitment to Security

JobGuard is committed to protecting user data and maintaining a secure platform. We implement industry-standard security practices to ensure the safety and privacy of our users.

Data Protection

What We Collect: UserFirst name, last name, email address, and password (hashed and salted)

  • Job listing data for analysis
  • Job risk assessment results

How We Protect It:

  • All data transmitted via HTTPS/TLS encryption
  • Passwords hashed using industry-standard algorithms
  • Regular security audits and updates
  • Compliance with data protection best practices

Authentication & Authorization

We use secure OAuth 2.0 authentication with Google. Tokens are:

  • Validated on every request
  • Stored securely in browser localStorage
  • Never logged or exposed in URLs (except during OAuth redirect)
  • Automatically cleared on logout

Content Security

What We Do NOT Do:

  • Store login credentials in plain text
  • Share user data with third parties
  • Display misleading or deceptive content
  • Perform phishing or social engineering attacks
  • Inject malicious scripts or malware

Browser Security

We implement the following security headers:

  • X-Content-Type-Options: nosniff - Prevents MIME type sniffing
  • X-Frame-Options: SAMEORIGIN - Prevents clickjacking
  • X-XSS-Protection - Enables XSS protection
  • Strict-Transport-Security - Enforces HTTPS

Transparency

Our Purpose: JobGuard helps users identify suspicious job opportunities and potential employment scams by analyzing job listings for red flags.

How It Works:

  • Users input job description or URL
  • Our system analyzes for common scam indicators
  • Results displayed with detailed reasoning
  • No data is shared or sold

Reporting Security Issues

If you discover a security vulnerability, please report it responsibly to our security team. Do not publicly disclose vulnerabilities before we have a chance to fix them.

Updates to This Policy

We may update this security policy from time to time. Changes will be posted on this page with an updated date.
